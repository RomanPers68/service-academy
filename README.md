# Service Academy

Обучение персонала ресторана в виде мини-приложения Telegram: уроки по ролям,
тренажёры по меню и бару, график смен, наставник на базе ИИ.

## Что где лежит

| Папка | Что внутри |
|---|---|
| `ui/` | Экраны и всё, что рисуется. Файл на экран или группу близких экранов |
| `lib/` | Правила без интерфейса: генератор графика, движок сборки коктейлей, поиск КБЖУ, общие мелочи |
| `data/` | Содержимое: уроки по ролям, коктейли, меню-примеры, справочник, глоссарий, пищевая ценность |
| `api/` | Обработчики на стороне Vercel |
| `supabase/` | Миграции и функции сервера. Порядок применения — в `supabase/README.md` |
| `tests/` | Проверки: движки, сопоставления, рендер экранов |
| `scripts/` | Служебные скрипты (проверка целостности содержимого) |
| `public/` | Иконки, фото блюд и справочника, сервис-воркер |
| `docs/` | Заметки по обновлению, архив журнала изменений |

Журнал изменений — `CHANGES.md` в корне: последние сорок дополнений.
Всё, что старше, — `docs/CHANGES-archive.md`.

## Работа с проектом

```bash
npm install
npm run dev          # локальный запуск
npm run check:all    # целостность содержимого + области видимости + тесты + сборка
npm run build        # сборка в dist/
```

`npm run check:all` стоит прогонять перед каждой заливкой: он ловит
необъявленные имена, битые ссылки в уроках и падения экранов при рендере.

## Заливка

Проект живёт на Vercel и собирается из репозитория сам. Файлы заливаются
**распакованными**, папками — если положить архив целиком, сборка пройдёт по
старой версии и на телефоне ничего не изменится.

Какая версия доехала, видно в приложении: Меню → под названием ресторана
строка вида «сборка v24». Приложение и само сверяет сборку при открытии и
перезагружается, если вышла новая.

## Ключи и доступы

В репозитории их нет. Адрес и ключ Supabase — в переменных окружения Vercel,
ключи функций — в настройках проекта Supabase.
