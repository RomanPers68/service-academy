# Аудит Service Academy — 21.09.2026

Функционал и визуальный язык «морозный лёд», обе темы.

## Как проверялось

- **44 экрана-вида** (30 сотрудника + 14 руководителя) × **2 темы** = 88 прогонов в Chromium
  как на телефоне 390×844, без сети — приложение в офлайн-режиме с кэшем профиля.
  Каждый экран прокручен целиком, по частям.
- **Контраст** меряется для каждой надписи против того, что реально под ней нарисовано:
  второй снимок делается с прозрачным текстом, цвет надписи накладывается на этот фон
  с учётом прозрачности всех родителей. Нормы WCAG: 4,5:1 для обычного текста, 3:1 для
  крупного. «Плохо» — ниже 3:1, «слабо» — от 3 до 4,5.
- **Стекло**: у каждой поверхности со скруглением от 10 px и фоном проверено внутреннее
  свечение (`inset`), блик по верхней кромке и полупрозрачность.
- **Не проверено**: экзамен, сертификат изнутри, «роль завершена», карточка игрока (нужны
  данные прохождения); график с данными сервера; тесты и практики изнутри урока; диалог по ходу.
- **Ограничения просмотра**: вместо Georgia — Lora (переносы могут отличаться), React 19 вместо 18.

Инструмент — `tools/claude/audit.mjs`, листы со снимками всех экранов — отдельными файлами.

## 1. Функционал

**Падений — 0, ошибок в консоли — 0** на всех 88 прогонах. Исключение — давняя ошибка SVG
в «Сборке руками» (`xMidYEnd`, журнал, правка 117): картинку не меняет, пишет в консоль.
Экраны без данных сервера показывают честные пустые состояния или «нет связи».

## 3. «Морозный лёд»

**Основа в порядке.** Базовая карточка `T.modCard` — полноценное стекло в обеих темах
(полупрозрачность, внутреннее свечение, блик по кромке), и большинство поверхностей её
наследуют.

**Плоские поверхности** — без свечения и без блика:

- «Учусь»: карточки «Аудио-уроки», «Кухня», «Первая неделя»;
- «Рейтинг»: «Сотрудник недели» и «Рекорды команды»;
- SOS: плашка «112 — единый номер · 103 — скорая»;
- урок: подсказка «Карточки ↔ лента».

Дорожки переключателей (чек-листы, аналитика, меню, колода) тоже без блика, но это
углублённые дорожки — так и задумано.

**Выпадения из светлой темы:**

- «Вход» остаётся тёмным целиком;
- подсказка «Карточки ↔ лента» в уроке — тёмная плашка на светлом экране.

**Эмодзи вместо иконок приложения:** ✨ («Учусь»: «Остальные инструменты откроются…»),
🔎 (поиск), 👋 (урок), ❄ (колода), ⚠ (меню, ошибка загрузки), 🎉 и 🏆 в пустых состояниях
(«Ошибок нет», «Все уроки пройдены»). 😐 в полоске настроения гостя — часть механики,
её не трогать.

**Шрифт:** в AI-наставнике часть надписей идёт без шрифта приложения — браузер подставляет
свой по умолчанию. Нужно найти эти элементы.

**Содержание:** в «Заданиях дня» у главы справочника всегда подписано «Курс: Сервировка»,
даже если глава из курса про кофе или вино.

## 4. Предлагаемый порядок правок

1. **Токены** — одна правка закрывает десятки экранов: `MUTED_3` (тёмная), стрелки `›`,
   знак «SA» в светлой, неактивные вкладки. Показать макетом 2–3 варианта яркости.
2. **Светлые варианты там, где их нет:** золото текстом → `#8B6A30`, зелёный → `GREEN_DARK`,
   цвета ролей → затемнённый вариант, подписи «Заданий дня», «+ Добавить заметку».
3. **Стекло** для плоских поверхностей; светлые версии входа и подсказки урока.
4. **Эмодзи → SVG** из набора приложения.

После каждого шага — повторный аудит тем же скриптом: цифры в таблице выше должны падать.
