# Приложение для Android без Google Play

Есть два пути. Первый — за минуту и без файлов. Второй — настоящий APK: ставится
как из магазина, его можно разослать в чат.

## Путь 1 — «Установить приложение» в Chrome

Приложение уже собрано как устанавливаемое: манифест, иконки, работа без сети,
уведомления. Сотруднику нужно:

1. Открыть `https://service-academy-16te.vercel.app` **в Chrome** (не в Telegram).
2. Меню браузера (три точки) → **Установить приложение**.
3. На рабочем столе появится иконка. Открывается в своём окне, без адресной
   строки, уведомления приходят от имени приложения.

Вход по коду работает и вне Telegram, так что ничего не сломается.

## Путь 2 — APK-файл (с v222 собирается сам)

APK собирается на GitHub, руками ничего делать не нужно. Ссылка всегда одна и та же:

**https://github.com/RomanPers68/service-academy/releases/download/android-test/service-academy.apk**

Страница выпуска с описанием: https://github.com/RomanPers68/service-academy/releases/tag/android-test

### Как поставить

1. Открыть ссылку на телефоне и скачать файл.
2. Android попросит разрешить установку из этого источника (Chrome, «Файлы» или
   Telegram — откуда открыли). Разрешить.
3. **Установить.** Play Protect может предупредить о неизвестном приложении — это
   нормально для файла не из магазина: **Всё равно установить**.
4. Открыть «SA» и войти по коду сотрудника. Если на этом телефоне уже входили в
   Chrome, вход общий и код не понадобится.
5. Уведомления: «Напоминания» → «Куда присылать» → «Только телефон» или
   «Telegram и телефон». Android спросит разрешение — **Разрешить**.

### Что внутри

- Пакет `app.serviceacademy.twa`, имя в настройках — «Service Academy», под
  значком — «SA».
- Сайт открывается во весь экран через Chrome (Trusted Web Activity). Код, кэш,
  вход и уведомления те же, что у сайта; уведомления приходят от имени приложения.
- Ссылки на сайт открываются в приложении.
- На телефоне должен быть Chrome.

### Когда пересобирается

Сама — когда меняются папка `android/`, манифест сайта или значки. Вручную:
GitHub → **Actions** → **android-apk** → **Run workflow**. Экраны и функции
приезжают с сайта, для них пересобирать не нужно. Новый APK ставится поверх
старого, ничего удалять не надо.

### Ключ подписи

- Пароль — секрет `APK_KEY_PASSWORD` в GitHub (Settings → Secrets and variables →
  Actions). **Не менять и не удалять:** без него следующая сборка не подпишется, а
  APK с другим ключом не встанет поверх старого.
- Сам ключ лежит в `android/signing-key.enc`, зашифрованный этим паролем.
- Отпечаток ключа прописан в `public/.well-known/assetlinks.json`. По нему Android
  понимает, что приложение и сайт одного хозяина, и прячет адресную строку.

### Старая сборка из PWABuilder

Раньше APK собирали на pwabuilder.com (пакет `app.vercel.service_academy_16te.twa`).
Её строка в `assetlinks.json` оставлена, чтобы старые установки работали как
раньше. Если на телефоне стоят обе, старую лучше удалить, чтобы не путаться.

### Поворот экрана (v50)

С v50 приложение работает и лёжа: в манифесте `"orientation": "any"`.

- **Путь 1 (иконка из Chrome)** — Chrome сам подтягивает новый манифест, обычно
  за пару дней. Чтобы сразу: удалить иконку и установить заново.
- **Путь 2 (APK)** — сборка с v222 поворачивается вместе с телефоном. Старая
  сборка из PWABuilder, если её собирали до v50, остаётся только портретной.

## Про iPhone

APK там не работает. Для iOS путь один — Safari → «Поделиться» →
**На экран «Домой»**. Получается такая же иконка и полноэкранный режим.
