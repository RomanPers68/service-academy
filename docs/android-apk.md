# Приложение для Android без Google Play

Есть два пути. Первый — за минуту и без файлов, второй — настоящий APK,
который можно разослать в чат.

## Путь 1 — «На главный экран» (проще всего)

Приложение уже собрано как устанавливаемое: манифест, иконки, работа без сети.
Сотруднику нужно:

1. Открыть `https://service-academy-16te.vercel.app` **в Chrome** (не в Telegram).
2. Меню браузера (три точки) → **Установить приложение** или
   **Добавить на главный экран**.
3. На рабочем столе появится иконка. Открывается в своём окне, без адресной
   строки — от обычного приложения не отличить.

Вход по коду работает и вне Telegram, так что ничего не сломается.

## Путь 2 — APK-файл

Нужен, если хочется раздавать файл в чате или ставить на телефоны, где Chrome
не предлагает установку.

### Что делаем

1. Открыть **pwabuilder.com**, вставить адрес приложения, нажать **Start**.
2. Дождаться проверки — она покажет, что манифест и воркер в порядке.
3. **Package for stores → Android → Generate**.
   - Package ID оставить `app.serviceacademy.twa` (он уже прописан в
     `public/.well-known/assetlinks.json`);
   - галочку «Include source code» можно не ставить.
4. Скачается архив. Внутри:
   - `app-release-signed.apk` — то, что ставится на телефон;
   - `assetlinks.json` — файл подтверждения;
   - `signing-key.keystore` и пароли — **сохранить и не терять**: без них
     следующая версия APK не встанет поверх старой.
5. Открыть скачанный `assetlinks.json`, скопировать оттуда значение
   `sha256_cert_fingerprints` и вставить его в файл проекта
   `public/.well-known/assetlinks.json` вместо `ЗАМЕНИТЬ_НА_ОТПЕЧАТОК_ИЗ_PWABUILDER`.
6. Залить изменённый файл на GitHub и дождаться сборки.

Шестой шаг обязателен: без совпадения отпечатка Android покажет внутри
приложения адресную строку браузера.

### Как ставить на телефон

Отправить `app-release-signed.apk` в чат, открыть на телефоне, разрешить
установку из этого источника. Android один раз предупредит, что файл не из
Play — это нормально для раздачи внутри компании.

### Про обновления

APK — это оболочка, содержимое грузится с сайта. Значит, **все обновления
приезжают сами**, как сейчас: залил на GitHub, и у всех новая версия.
Пересобирать и рассылать APK нужно только если поменяются иконка, название,
адрес сайта или ориентация экрана.

### Поворот экрана (v50)

С v50 приложение работает и лёжа: в манифесте `"orientation": "any"` (было
`"portrait"`). В Telegram и в браузере поворот работает сразу после выкладки.

- **Путь 1 (иконка из Chrome)** — Chrome сам подтягивает новый манифест при
  запуске, обычно в течение пары дней. Чтобы сразу: удалить иконку и
  установить заново.
- **Путь 2 (APK)** — ориентация зашита в APK при сборке: APK, собранный до
  v50, остаётся только портретным. Чтобы он поворачивался, собрать APK заново
  (шаги 1–4) **тем же ключом**: в PWABuilder в разделе **Signing key** выбрать
  «Use mine» и загрузить сохранённый `signing-key.keystore` с паролями. Тогда
  новая версия встанет поверх старой без удаления, а отпечаток в
  `assetlinks.json` менять не придётся.

### Про iPhone

APK там не работает. Для iOS путь один — Safari → «Поделиться» →
**На экран «Домой»**. Получается такая же иконка и полноэкранный режим.
