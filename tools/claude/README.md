# tools/claude — проверки и просмотр для работы Claude

Не часть приложения: Vite собирает только то, что подключено из `main.jsx`,
сюда он не заглядывает. Эти файлы нужны песочнице Claude — там есть
TypeScript, esbuild и Chromium. Раньше проверки жили вне проекта и терялись
вместе с разговором.

## Проверки — после каждой правки

    node tools/claude/sa-check.mjs .

build (полная сборка esbuild от main.jsx) · check (синтаксис каждого файла) ·
jsxlint · flexhint · dupimport · refcheck · scope (tsc, необъявленные имена).
Норма — «Всё чисто.», ложных срабатываний нет.

## Юнит-тесты без vitest (v157)

    node tools/claude/run-tests.mjs .                 # все tests/*.test.js
    node tools/claude/run-tests.mjs . v157.test.js    # один файл или несколько

В песочнице пакеты не ставятся, vitest нет. `run-tests.mjs` собирает каждый файл тестов esbuild, подставляя вместо
vitest `vitest-shim.mjs` (describe, it, expect с теми сопоставителями, которыми пользуются тесты проекта, хуки, `vi` —
подмена таймеров), и запускает его отдельным процессом из корня проекта. Вывод — упавшие тесты и строка «файлов N,
тестов прошло N, упало N». На настоящем vitest (`npm test`) тесты идут без изменений.

Настоящий vitest идёт на GitHub при каждой заливке (`.github/workflows/test.yml`, Доп. 482): у коммита — галочка или
крестик, журнал — `gh api repos/<владелец>/<репозиторий>/actions/jobs/<id>/logs`. Чтобы не узнавать о падении уже там:

- `.js` здесь читается как у Vite — без разметки JSX. Разметка в тестах — только в `.test.jsx` или через
  `React.createElement`.
- Главная зависит от часа (приветствие, свет, вечерние огни), а GitHub гоняет тесты по UTC. Перед заливкой — три прогона:
  `TZ=Asia/Kamchatka`, `TZ=UTC`, `TZ=America/New_York node tools/claude/run-tests.mjs .` (день, ночь, вечер).

## Просмотр в браузере

    mkdir -p ~/.config/fontconfig && cp tools/claude/fonts.conf ~/.config/fontconfig/ && fc-cache -f
    mkdir -p /home/claude/preview && cp tools/claude/*.mjs /home/claude/preview/
    node /home/claude/preview/build.mjs "$PWD"
    cd /home/claude/preview && node gen-sweep.mjs dark && SRC=<путь к проекту> node shoot.mjs sweep-dark.json

Приложение открывается как телефон 390×844 без сети и само уходит в
офлайн-режим с кэшем профиля. Сценарий — JSON: `who` (staff / admin),
`theme` (dark / light), `role`, `hints` (какие подсказки ещё не видены),
`storage`, `steps`: `nav` (экран), `click`, `wait`, `shot`, `expectHint`,
`align` (замер рамки подсветки), `eval`, `scroll`. Снимки — в
`/home/claude/preview/shots`.

Ограничения: вместо Georgia шрифт Lora (переносы могут отличаться), React 19
вместо 18, график смен без данных сервера не открывается.

## Формат «у стола» (v27)

    node /home/claude/preview/build.mjs "$PWD" && cd /home/claude/preview && node e2e-table.mjs

Меню раздела, «Закрепить у стола» после урока (промах → «Спасти ситуацию»,
повтор ошибки «напоследок», чек, «Дальше: следующий урок»), продолжение урока
с той же карточки, практика у стола (тарелки, выход посреди раунда, продолжение
раунда, классический вид), кнопка «Назад» Telegram. Две темы: тёмная 390×844 и
светлая 360×780. Снимки — в `/home/claude/preview/shots-table`.

    node e2e-table2.mjs

Проверки после независимого ревью: раунды помнятся по каждой практике, таймер
стоит под вопросом «Выйти?», промах в классическом виде попадает в «Работу над
ошибками», пройденный урок открывается с начала, серия отмечается в момент итога
раунда, вспышка «Серия 7 дней» — поверх слоя урока.
